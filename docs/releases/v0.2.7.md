## Publication note

The `v0.2.7` tag points to the merged lifecycle fix, but its manifest still reports `template_version: 0.2.6`. The tag is retained unchanged. Use `v0.2.8` as the consistent release target for new generated repositories and template updates.

None.

## Migration

Close update pull requests targeting `v0.2.7` and rerun the update workflow after `v0.2.8` is published. Repositories based on `v0.2.6` can update directly to `v0.2.8`; older repositories should follow the documented `v0.2.3 -> v0.2.4` bridge first.
