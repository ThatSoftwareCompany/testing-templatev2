# Release v0.4.0

breaking: false

This release hardens the backend template's supply chain and makes template updates safer to review. The frontend template remains separate and unchanged.

## Added

- Weekly grouped Dependabot updates for Go modules and GitHub Actions.
- Blocking dependency review for high and critical dependency findings.
- Exact-version `govulncheck` execution in CI.
- Docker Scout scanning for fixable high and critical vulnerabilities in the production image, using read-only repository Actions secrets for Docker Hub authentication.
- Dependabot workflow secret documentation for Docker Scout, including the required duplicate Dependabot secrets.
- Full-SHA pin validation for every GitHub Action, with human-readable version comments.
- `actionlint v1.7.12` validation for all GitHub Actions workflow YAML.
- Versioned security-exception metadata with expiry, ownership, issue, and exact finding matching.
- Machine-readable template path ownership metadata.
- Updater dry-run mode, release-note reporting, safe pre-applied-file detection, and explicit conflict reports.
- A breaking-update CI gate that requires manual migration and review.
- Manifest consistency checks for direct Go module dependencies.

## Compatibility

The runtime API and authentication contract remain compatible with `v0.3.1`. PostgreSQL compatibility remains `16+`; the minimum compatible Go version remains `1.26.0`, while CI and Docker validate Go `1.26.7`.

## Migration instructions

No application migration is required for this non-breaking release. Derived repositories should configure `TEMPLATE_UPDATE_TOKEN`, review the generated updater PR, and keep product code in application-owned paths. If a future release declares `breaking: true`, the updater will create a clearly marked PR that must be migrated manually before merge.

Artifact attestations remain an evaluated follow-up and are not part of this release.
