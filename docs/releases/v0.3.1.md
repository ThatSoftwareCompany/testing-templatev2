# Release v0.3.1

breaking: false

This patch release reconciles the published `v0.3.0` authentication release with the protected application-route extension point that was merged afterward.

## Added

- Exposed `app.Dependencies.Auth` for application-owned route composition.
- Added explicit role and permission middleware helpers for protected business routes.
- Added validation and documentation for the development Ed25519 key generator.

## Compatibility

The authentication contract, database schema, cookie policy, and public operational routes are unchanged from `v0.3.0`. Existing generated repositories should review the application-owned `internal/app/routes.go` contract before consuming this release.

The minimum compatible Go version remains `1.26.0`; CI and Docker validate Go `1.26.7`. PostgreSQL compatibility remains `16+`.
