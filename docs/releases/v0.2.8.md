# Release v0.2.8

breaking: false

## Summary

Corrected publication of the template lifecycle hotfix with consistent version metadata.

## Fixed

- Publish the merged module-path normalization and legacy bridge fixes under a matching manifest version.
- Prefer a valid recorded template commit during update detection, preventing immutable tag corrections from replaying already-applied changes.
- Keep lifecycle fixtures independent of optional developer tools and global Git identity configuration.
- Preserve custom Go module paths and application-owned routes during update validation.

## Incompatible changes

None.

## Migration

The immutable `v0.2.6` and `v0.2.7` tags should not be moved or reused. Close any generated update pull request targeting those tags and rerun the update workflow after `v0.2.8` is published. Repositories currently based on `v0.2.6` can update directly to `v0.2.8`; older repositories should follow the documented `v0.2.3 -> v0.2.4` bridge first.
