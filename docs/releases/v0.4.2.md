# Release v0.4.2

breaking: false

This release adds a controlled metadata bootstrap for derived repositories that still use an older template updater.

## Added

- `scripts/template-update-bootstrap.sh` synchronizes template-managed manifest metadata before an update.
- The update workflow commits the bootstrap metadata separately before applying the normal template patch.
- Provenance and generated-project fields remain unchanged until the normal update succeeds.
- Dry-run and recovery behavior are covered by the lifecycle suite.

## Migration instructions

Repositories generated before `v0.4.2` require one reviewed bootstrap commit during their first update. Preserve `template_version`, `template_commit`, `generated_from`, `generated_project`, and application-owned routes. Future updates from a repository containing the `v0.4.2` workflow run the bootstrap automatically.
