# Release v0.4.1

breaking: false

This hotfix keeps derived repository manifests synchronized when the template updater changes direct Go dependency versions.

## Fixed

- The updater now copies the template's `dependency_versions` metadata into the derived repository manifest during a successful update.
- Dry-run reports include `.template/manifest.json` when dependency metadata would change.
- Lifecycle coverage verifies that a stale `pgx` manifest entry is repaired during a clean-room update.

## Migration instructions

No application migration is required. Re-run the template updater after configuring the required repository secrets. Review the generated pull request and confirm that application-owned files, especially `internal/app/routes.go`, remain unchanged.
