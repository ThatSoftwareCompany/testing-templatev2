# Release v0.2.6

breaking: false

## Summary

Lifecycle compatibility hotfix for generated repositories with custom Go module paths.

## Fixed

- Restrict module-path normalization to Go sources and `go.mod`, preserving canonical template references in scripts and documentation.
- Make lifecycle fixtures derive the source module path instead of embedding a string that can be rewritten during an update.
- Exercise the real compatible bridge from `v0.2.3` to `v0.2.4` and then `v0.2.5`.
- Reject canonical Go imports in derived lifecycle fixtures.

## Incompatible changes

None.

## Migration

Repositories generated before `v0.2.4` must first update to `v0.2.4` using the current updater, then update to `v0.2.6`. Repositories already based on `v0.2.4` or newer can update directly.

## Publication note

The `v0.2.6` tag points to the previous foundation commit. The tag is retained unchanged; use `v0.2.8` for the corrected lifecycle release.
