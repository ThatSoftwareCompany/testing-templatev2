# Release v0.2.5

breaking: false

## Summary

Foundation hardening release for the Go API template. This release strengthens the operational test matrix and validates the generated-repository lifecycle without introducing authentication or product-route changes.

## Added

- PostgreSQL pool, migration, error-store, setup-script, and template-updater coverage.
- Temporary-repository lifecycle tests for legacy bootstrap, version transitions, custom module paths, and application-owned routes.
- Docker development/production build and smoke validation in CI.
- Behavioral checks for no-database execution, HTTP security behavior, and template metadata.

## Fixed

- CI now validates the complete foundation quality gate, including module tidiness, checksum verification, race tests, shell checks, and template builds.
- CI and Docker use the latest validated Go 1.26 patch while the template minimum remains Go 1.26.0.

## Incompatible changes

None. Authentication, authorization, and the public internal error endpoint remain planned for v0.3.0.

## Migration

No migration is required for generated repositories. Run the derived-repository template update workflow, review the generated pull request, and resolve any application-specific conflicts manually.
